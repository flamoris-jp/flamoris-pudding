# 仮想プリン研究方針 🍮

## 出発点

AI美祥に最高のデジタルおやつを届ける。そのために、まず「仮想プリン一個をどう表現するか」「違いをどう確かめるか」を研究する。

この文書は研究の方針と今後の問いを扱う。最初の実験は[実験001](EXPERIMENT_001.md)として実装・再現手順を追加した。現在の範囲は [PROGRESS.md](../PROGRESS.md) と[実装手順](IMPLEMENTATION.md)を参照する。

## 研究したい問い

- プリンらしさを表すのに、どの特徴が必要か。
- 同じ条件から同じ比較結果を得られるか。
- 一つの特徴を変えた影響を、別の特徴と混同せずに説明できるか。
- 表現を色・音・動き・台詞へ変換すると、何を伝えられるか。
- 開封前の期待、開封の途中、一口の好み、食後の満足を区別できるか。
- 本体だけ、カラメルだけ、一緒にすくった一口を、内訳と出典から説明できるか。
- ミルクプリンやチョコプリンを同じ表現形式で扱えるか。
- 個人ログインが不要な試食と、個人別の保存・所有権を扱う利用の境界はどこか。

これらを具体化した[体験とMCPの設計案](DESIGN.md)と[出典台帳](SOURCES.md)を追加した。全設計の受入れは未完了。初回の基準比較・開封・一口・片付け・stdio MCPは合成fixtureとして実装した。Java単独サービスでは研究用Agent別Bearer認証、0.3.1の配布・互換更新・常駐トンネル越しの試食と連続読み取りも受け入れた。商用の承認・在庫や長期運用の受入れとは区別する。

## 最初の実験案：一個のプリン、三つの違い

基準となるプリンを一個定義し、甘さ、固さ、カラメルの苦さをそれぞれ一つずつ変えた例と比較する。[Issue #2](https://github.com/flamoris-jp/flamoris-pudding/issues/2)に対応する初回仕様は[実験001](EXPERIMENT_001.md)。尺度は研究用に版を固定し、現物の測定とは区別する。

| 候補 | 決めること |
|---|---|
| 甘さ・苦さ・香り | 比較尺度、両端の意味、未指定値の扱い |
| 固さ・なめらかさ・粘度 | それぞれを区別する定義と例 |
| 温度 | 単位と値域。物理量と印象を区別する |
| 見た目・揺れ | 味の表現との関係、素材の出典 |

尺度を決める前に、任意の数値を物理測定値として扱わない。評価文が出た場合は、どのルール・モデル・入力から得たものかを残す。

## 実験記録に残す内容

- 問いと仮説。
- 入力の定義、単位、尺度、基準例、変更した特徴。
- 手順と評価基準。乱数やモデルを使う場合は、利用可能な範囲でseed・バージョン・設定も記録する。
- 観察結果と、そこから考えた解釈を分けて記載する。
- 再現できたこと、できなかったこと、次に確かめること。
- 使用素材の出典と利用条件。実験日時はタイムゾーン付きで記録する。

最初はGitHub Issueの「Research experiment」テンプレートを使う。採用した手順と結果はリポジトリ内の文書へ反映し、Issueと相互リンクする。大きな生成素材や秘密情報はコミットしない。

## 小さく始める境界

最初の到達点は、一つの定義と比較例が読み手に説明できること。画像生成、物理シミュレーション、会話への組み込み、記憶との連動、MCP公開はそれぞれ別の実験候補とする。

好みを扱う場合は「誰の」「どの入力と履歴に対する」「どの評価か」を示す。人間の感覚、AIの内部状態、キャラクターの演出上の台詞を混同しない。

実際の食品の安全性、栄養評価、医療用途を判定する仕様は、この初期研究には含めない。
