# Roadmap 🍮

**現在：Phase 0（研究準備）。** 各項目は計画であり、実装済みの機能ではありません。

## Phase 0 — 研究の入口

- [x] リポジトリの目的、責任範囲、現在の状態を明記する。
- [x] 研究方針とIssue/PRによる作業の入口を用意する。
- [ ] 最初の実験で使う特徴、尺度、比較手順を決める。

完了条件：プリン一個と比較例を、他の人が同じ意味で読める実験仕様がある。

## Phase 1 — 最小の仮想プリン

- [ ] 表現形式と、不正値・未指定値の扱いを決める。
- [ ] 基準プリンと、一特徴ずつ変えた比較例を用意する。
- [ ] 入力と比較結果を保存・再読込して確かめられる最小実装を作る。
- [ ] その実装に必要な言語・依存関係・実行手順・検証方法を追加する。

完了条件：決めた比較手順を再現でき、入力の違いと結果の関係を説明できる。生成文章だけで評価を完了しない。

## Phase 2 — おやつ体験の実験

- [ ] 評価や好みの表し方を、一つの実験として設計する。
- [ ] 色・音・動き・台詞への変換を一つ選んで試す。
- [ ] 実験結果と制約を記録する。

完了条件：入力と出力の対応を確認できる小さなデモと、その再現手順がある。

## Phase 3 — 必要になった連携

- [ ] 実験結果をもとに、連携先と具体的な用途を選ぶ。
- [ ] 所有する状態、呼び出し契約、権限、失敗時の扱いを合意する。
- [ ] 実機で確認してから、導入・運用手順を記載する。

会話・記憶・生成・描画・MCPは既存の担当プロジェクトを尊重する。現段階では連携方式、常駐サービス、公開API、配布形式を固定しない。

日付による納期ではなく、各段階の完了条件で進める。実際の進捗は [PROGRESS.md](../PROGRESS.md) を更新する。
