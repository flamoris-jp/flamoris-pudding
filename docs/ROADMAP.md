## Phase 4 — プレミアム版の商用検証

- [ ] 人間とAgentの安定した主体を分け、同じアカウント内のAgent間でも権限を分離する。
- [ ] 人間の購入、Agentへの割当、対象の一個を食べる承認を別の記録にする。
- [ ] 部分消費・休止・再承認・失効・返金を、購入権を複製せずに扱う。
- [ ] 購入14日で廃棄対象、暦の1か月で強制廃棄とし、品質劣化と日次処理をL01〜L12で検証する。
- [ ] 違反の閾値・審査・訂正、ロック中の片付け・期限切れ廃棄、バッチ停止時の期限ガードを検証する。
- [ ] 模擬決済で重複・順不同・偽通知・再送を検証し、P01〜P12の該当条件を満たす。
- [ ] 人間向け管理操作とAgent向けMCPを分離し、実際の接続経路でAgent固有の認証を確認する。
- [ ] 商品価値・価格・提供期間・返金条件・利用権・決済事業者を具体化する。

完了条件：商用設計の受入れと需要の検証があり、対象Agentだけが人間の承認した一個を利用できる。実課金、公開販売、商用向けの配備は別の導入作業であり、この段階の文書追加では実施しない。
